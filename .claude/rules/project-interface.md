# ObsidiNote: the interface (map, search, List)

Moved word for word from AGENTS.md "Architecture" (2026-11-25); AGENTS.md points here. Same upkeep
as there: only what the code cannot show, changed in the same turn as the code.

- Round 1 interface (2026-11-13): `src/search/` (`query.ts` is the one search language and ranking for the graph search and the Ctrl+K switcher, `model/keys.ts` `isFindKey`; the switcher hands a pick to the graph as a `FindRequest`), `src/model/origins.ts` + `src/add/pasteOrigin.ts` (where a page without an address came from: `obsn.origin`, the composer's "From" choice prefilled from the pasted HTML, Edit's "From" field; server table `$script:Origins` in `lib/NotebookStructure.psm1` and `Test-OriginId` refuse other ids; both pinned by `tests/fixtures/origins.json`: change all three together; a waiting Add keeps it on its Intake item), `src/graph/sourceView.ts` (the Sources view, 2026-11-14: `bySource` turns `GraphModel.sources` into the areas, so layout/lines/hover run unchanged; only the map's areas switch, the page window, filters and List keep the topics; `groupBy` is session state; each page's `sourceId` and the list come from `lib/GraphModel.psm1` `Get-GraphSources` with `Get-LinkSource` in `lib/NotebookStructure.psm1`, next to the link rules (same `internalHosts`/company names as filing, `Get-ServerLinkRules`, so internal vs web agree), tests in `tests/GraphModel.Tests.ps1`), `src/graph/weights.ts` (the one definition of a page's link weight, dot size input and hubs, derived from the edges in `normalizeGraph`; the server sends no link count, unlinked or hub flag), `src/graph/layout.ts` `packOrder` + `packAreas(..., links)` (areas placed so topic lines need no bend: linked topics next to each other, strongest first; a spot pays `CROSS_PENALTY` per strength unit of a line that would pass another area; ratchet test in `layout.test.ts`), `bundleEdges` (one line per topic pair, width = summed strength; ends on the facing side, `spreadEnds` along the rim, cubic at right angles; `routeAround` bends it round every third area in its way at `AREA_GAP / 2` from the rim (the middle of the packing gap, so a bend never needs a bend; keep AREA_GAP >= 2 * ROUTE_CLEARANCE + margin), checked by sampling the curve in `layout.test.ts`; drawn UNDER the solid `--kg-area`, so `--kg-area` must stay opaque; `restingBundles` = 8 at rest, a focused page's area gets all of its own in `.kg-focus-bundles`; cross-topic page links only in the focus layer) and `onePerPair` (a mutual link drawn once; graphIndex `out`/`in` keep both directions for the page window and Edit), and `view.ts` `labelMode` / `lineMode` (all topic lines from `ALL_LINES_ZOOM`) / `placeAreaLabels` (topic name centred on its own area; GraphStage hides it while the pointer is over the area or one of its pages is focused) / `cardPosition` / `fitViewport(..., FIT_BOTTOM)` (readability, 2026-11-14, all pure with tests in `layout.test.ts` / `view.test.ts`), `src/graph/filters.ts` (filters -> visible ids; hidden pages are not drawn or navigable, the layout is not rerun; the List gets the same set through `matches`), `src/graph/history.ts` (dialog Back/Forward), `src/graph/mentions.ts` (mentions computed in the interface from titles/aliases/summaries; the server sends links only), `src/graph/table/` (the List table, pure `tableModel.ts`), `src/add/pasteMarkdown.ts` (pasted HTML -> Markdown; `looksLikeMarkdown` mirrors `Test-MarkdownText`, pinned by `tests/fixtures/paste-markdown.json` from vitest and `tests/PasteMarkdown.Tests.ps1`: change both together). All view state (filters, sort, history, switcher model) lives in memory.
- Map series fold (D-077): `ui-src/src/graph/seriesFold.ts` (pure) folds the map's copy of the model by `seriesKey` (sent per page by `lib/GraphModel.psm1` `Get-GraphSeriesKey` = `Get-MeetingSeriesKey` of the series, or of the title for a meeting page without one from Today's meetings or with a date in its title; never compare series names any other way), one page per series (the series page, else the newest meeting; `seriesCount` on it; meeting links re-pointed, self-loops dropped, strongest per pair and kind); `KnowledgeGraph` draws `mapModel`/`mapIndex` (`useMapModel` in `useGraphView.ts`) and maps shown/matches/active through `dotOf` (`useMapIds`, pure parts in `seriesFold.ts`), while the List, search and page window keep the full model and index. Always on, also for a one-meeting series (D-077). Labels: `graph/pageLabel.ts` (`pageMapLabel`: short series name before the first "|" and the meeting count; every other page its title).

CI (`.github/workflows/ci.yml`) has two jobs: the Pester suite, and `ui` (npm ci, typecheck, lint, vitest and the injection scan, build, and "the committed ui/ matches a fresh build"); actions pinned by commit SHA (looked up with `gh api repos/<owner>/<repo>/commits/<tag>`, tag in the comment), a newer push cancels the run it supersedes.
